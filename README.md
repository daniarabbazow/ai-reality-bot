# AI REALITY — Telegram-игра «Real или AI?»

Игрок выбирает категорию и уровень, бот присылает картинки по одной,
нужно угадать: сделал фото человек или его сгенерировала нейросеть.

## Запуск

1. Создать виртуальное окружение и установить зависимости:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Получить токен у [@BotFather](https://t.me/BotFather), скопировать
   `.env.example` в `.env` и вставить токен:

   ```bash
   copy .env.example .env
   ```

   В `.env` должна получиться строка вида `BOT_TOKEN=123456:AA...`.

3. Запустить бота:

   ```bash
   python -m bot.main
   ```

## Как добавить новую категорию / уровень / элемент

Код трогать не нужно — всё делается через `content.json`. Элемент может
быть картинкой или текстом (стихом) — тип задаётся полем `"type"`.

- **Фото** (`"type": "photo"`, можно не указывать — это значение по
  умолчанию): обязательно поле `"file"` (относительный путь к файлу в
  `images/<category>/`), поля `"text"` быть не должно.
- **Текст** (`"type": "text"`): обязательно непустое поле `"text"` (строки
  стиха разделяются `\n`), поля `"file"` быть не должно.
- Общие для обоих типов поля: `"id"` — уникальный, `"answer"` — `"real"`
  или `"ai"`, `"note"` — служебный комментарий для автора (имя автора
  стиха или пометка «ИИ»); **игроку `note` никогда не показывается**.

Пример текстового элемента:

```json
{"id": "poems_l1_02", "type": "text", "answer": "real", "note": "Ф. Тютчев",
 "text": "Есть в осени первоначальной\nКороткая, но дивная пора —"}
```

- **Новый уровень** — добавить объект в массив `levels` категории
  (`level` — номер, `title` — подпись, `items` — список элементов).
- **Новая категория** — добавить объект в массив `categories`
  (`id`, `title`, `levels`); для картиночной категории — также создать
  папку `images/<category>/`.

При старте бот валидирует `content.json`: проверяет обязательные поля по
типу элемента (для фото — что файл существует, для текста — что текст
непустой), корректность `answer` и уникальность `id`. Если что-то не так,
бот не запустится и выведет понятную ошибку в консоль.

## Статистика

Ответы логируются в `bot.db` (таблица `answers`). Пример запроса, чтобы
посмотреть долю верных ответов по каждой картинке:

```sql
SELECT item_id, COUNT(*) AS answers, ROUND(AVG(is_correct) * 100) AS pct_correct
FROM answers GROUP BY item_id ORDER BY item_id;
```
